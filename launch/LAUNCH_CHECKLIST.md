## Daily Routine (15 min total)

1. Open `launch/DAILY_POSTING_BOARD.html` (30 sec)
2. Copy Title → Paste to YouTube Studio (1 min)
3. Copy Description → Paste (1 min)
4. Copy Tags → Paste (30 sec)
5. Upload video file (2 min)
6. Click through YouTube Studio steps (3 min)
7. Repeat for Channel 2 (7 min)
8. Copy Pinned Comment → Post (1 min)
9. Copy social post from `launch/ALL_SOCIAL_POSTS.md` → Post to X + Facebook (2 min)
10. Mark complete on posting board (10 sec)
