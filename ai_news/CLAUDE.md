# ai_news/ — AI Research Brief Directory

> Generated by `scripts/youtube_researcher.py` — auto-curated AI/ML news briefs from 27 YouTube channels.
> This directory feeds the **🧪 AI Research** tab in the TELLLEMTHATSME Command Center and the Atom feed at `/api/research/rss`.

## Directory Structure

```
ai_news/
├── CLAUDE.md                    ← You are here

├── AI_NEWS_CHANNEL.md           ← YouTube AI news channel strategy doc

└── archive/                     ← Last 30 daily briefs (auto-pruned)
    ├── 2026-06-11.md
    ├── 2026-06-10.md
    └── ...
```

## How Briefs Are Generated

`scripts/youtube_researcher.py` scrapes 27 curated AI YouTube channels, extracts video descriptions, and summarizes them via Claude API (through `server.js` /api/chat proxy). The output lands here.

### Commands

```bash
# Generate from curated channel list (no browser needed, uses Claude API)
python scripts/youtube_researcher.py --trending -o ai_news/CURRENT_AI_BRIEF.md

# Full scrape: open channels in browser, extract videos, summarize
python scripts/youtube_researcher.py --channel "Wes Roth" "Matt Wolfe" "Matthew Berman" --max-videos 5 -o ai_news/research.json

# Summarize from a previously-saved research.json (no browser needed)
python scripts/youtube_researcher.py --summarize-only --input ai_news/research.json -o ai_news/WEEKLY.md

# Test that bridge + Claude proxy are working
python scripts/youtube_researcher.py --test
```

### Prerequisites
- `server.js` running on `:8888` with `ANTHROPIC_API_KEY` env var (for Claude summarization)
- `bridge_server.py` on `:9876` with browser extension polling (for full scrape mode only)
- For `--trending` mode: only Claude proxy needed (no browser)

## Brief Format

Each brief follows this structure:
1. `# 🔥 Top 5 AI Stories` — headlines with source links
2. `# 🧠 New Models Released` — table: model | company | key feature
3. `# 💻 New AI Coding & Dev Tools` — tables by category (editors, builders, terminal, testing)
4. `# 🤖 New AI Agent Frameworks` — orchestration, MCP servers, browser auto, voice
5. `# ⭐ Trending GitHub Repos` — top 20 with why-trending notes
6. `# 📺 Best YouTube Channels` — daily/deep-dive/tutorial/long-form tables
7. `# 🎯 Recommended Actions` — 2-3 actionable recommendations

## Archive System

- Every refresh archives the previous brief to `archive/YYYY-MM-DD.md`
- Keeps last 30 days, auto-prunes older files
- Accessible via `/api/research/history` (JSON) and `/api/research/rss` (Atom feed)
- Individual archives served via `/_archive/ai_news/archive/YYYY-MM-DD.md`

## When Editing Briefs

- Keep the markdown structure intact — the command center tab parses headings
- Links should be full URLs (no relative paths)
- Tables must be valid markdown (the RSS feed strips them for plaintext summaries)
- The first `# Heading` becomes the Atom feed entry title
