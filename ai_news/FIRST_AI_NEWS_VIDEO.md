1. "5 AI Tools That Just Changed Everything This Week"

## Production Checklist

### Pre-Production
- [ ] Pick 5 AI tools/news items from this week
- [ ] Research each one (features, pricing, alternatives)
- [ ] Write the script segments
- [ ] Plan screen recordings (what to show for each tool)

### Recording
- [ ] Record screen demos for each tool (OBS Studio)
- [ ] Record voiceover (or use text-to-speech)
- [ ] Record intro/outro if doing facecam

### Post-Production
- [ ] Edit in DaVinci Resolve (free)
- [ ] Add transitions between segments
- [ ] Add text overlays for key points
- [ ] Add background music (low, non-distracting)
- [ ] Create thumbnail (Canva — dark bg, tool logo, 3-5 words)
- [ ] Export at 1080p minimum

### Upload
- [ ] Title: "5 AI Tools That Just Changed Everything This Week"
- [ ] Description: timestamps + links + social links
- [ ] Tags: AI news, artificial intelligence, AI tools, [tool names]
- [ ] Thumbnail: high contrast, tool logos, "5 AI TOOLS" text
- [ ] Category: Science & Technology
- [ ] Made for Kids: No
- [ ] Publish: Public

### Post-Upload
- [ ] Pin a comment: "Which tool are you trying first? Drop it below!"
- [ ] Share to X with thread
- [ ] Post to Facebook groups
- [ ] Create 30-60s TikTok/Reels clip from best segment
- [ ] Post to Instagram Stories
