## 🔬 Deep Dive

### General AI / Agent Ecosystem

### 1. kyrolabs/awesome-agents
**URL**: https://github.com/kyrolabs/awesome-agents
**Why it's #1**: The canonical reference for anyone building AI agents in 2026. Tracks:
- Agent frameworks (LangGraph, CrewAI, AutoGen, PydanticAI)
- Agent testing & evaluation tools
- Specialized agents (coding, browser, research, voice)
- Multi-agent orchestration patterns
- "Computer use" and desktop automation agents

**Use this when**: You're choosing an agent framework, or researching what's possible with autonomous agents.

### 2. patriksimek/awesome-mcp-servers-2
**URL**: https://github.com/patriksimek/awesome-mcp-servers-2
**Why it's essential for KARMA OS**: Our bridge and metrics servers should be MCP-compatible. This repo catalogs 100+ community MCP servers including:
- Filesystem, database, API connectors
- Browser automation (Playwright, Puppeteer wrappers)
- Cloud services (AWS, GCP, Azure)
- Dev tools (Git, GitHub, Jira, Linear)

**Use this when**: Adding MCP compatibility to KARMA OS tools, or finding MCP servers to integrate.

### 3. steel-dev/awesome-web-agents
**URL**: https://github.com/steel-dev/awesome-web-agents
**Why it's critical for the bridge**: Our AI Browser Bridge is essentially a web agent. This list tracks:
- Browser automation frameworks (Browserbase, Steel, Hyperbrowser)
- LLM-powered scraping tools
- "Computer Use" agents (Claude Computer Use, OpenAI Operator)
- Visual web agents (screenshot-based navigation)

**Use this when**: Researching browser automation improvements or comparing bridge alternatives.

### 4. promptslab/awesome-prompt-engineering
**URL**: https://github.com/promptslab/awesome-prompt-engineering
**Why it matters in 2026**: "Prompt engineering" has evolved into "context engineering." This repo covers:
- System prompt design patterns
- Automatic prompt optimization (DSPy, TextGrad)
- Prompt security (injection prevention)
- Vibe coding prompt patterns
- Chain-of-thought and reasoning frameworks

**Use this when**: Designing the summarization prompts for youtube_researcher.py, or building new agent skills.

### 5. hannibal046/awesome-llm
**URL**: https://github.com/hannibal046/awesome-llm
**Why it's enduring**: The most academically rigorous LLM resource list. Tracks:
- LLM architectures and training methodologies
- Alignment and safety research
- Inference optimization (vLLM, SGLang, llama.cpp)
- Benchmarking and evaluation frameworks

**Use this when**: Deeply understanding model capabilities, or choosing a model for a specific task.

### 6. modelcontextprotocol/servers
**URL**: https://github.com/modelcontextprotocol/servers
**Why it's canonical**: Anthropic's official MCP server repository. Contains reference implementations for:
- Filesystem, Git, GitHub
- PostgreSQL, SQLite
- Brave Search, Google Maps
- Puppeteer (browser control)
- Memory (knowledge graph)

**Use this when**: Learning MCP protocol patterns, or creating new MCP servers (use as templates).

### Claude Code Ecosystem

### 7. hesreallyhim/awesome-claude-code
**URL**: https://github.com/hesreallyhim/awesome-claude-code
**Why it's the canonical Claude Code list (~37k stars)**: The one-stop-shop for the entire Claude Code ecosystem. Tracks:
- Claude Code skills (reusable instruction packages)
- Hooks (pre/post tool execution triggers)
- CLI tools and orchestrators (multi-session management)
- MCP servers compatible with Claude Code
- Plugins and marketplace registries
- Agent configurations and sub-agent patterns

**Use this when**: You're building anything for Claude Code — skills, agents, hooks, or MCP servers. This is the first place to check for existing solutions.

### 8. ComposioHQ/awesome-claude-skills
**URL**: https://github.com/ComposioHQ/awesome-claude-skills
**Why it matters (~12k stars)**: The largest collection of Claude skills (1000+). Skills are reusable Markdown/YAML instruction packages that teach Claude how to perform specific tasks. Covers:
- Automation workflows (Slack, Jira, GitHub, Email)
- Coding patterns and frameworks
- DevOps and infrastructure
- Data processing and analysis
- Custom tool integrations

**Use this when**: You need a skill for a specific integration (Slack, Jira, etc.) — someone has probably already built it here. Also great for learning skill design patterns.

### 9. vijaythecoder/awesome-claude-agents
**URL**: https://github.com/vijaythecoder/awesome-claude-agents
**Why it matters (~8k stars)**: Focused specifically on orchestrated sub-agent teams — the "Subagent-Driven Development" approach. Tracks:
- Multi-agent architectures (Septim Agents Pack, etc.)
- Task decomposition patterns
- Agent communication protocols
- Specialized sub-agent templates

**Use this when**: You're scaling beyond single-agent Claude Code to multi-agent workflows. Directly applicable to KARMA OS's 5-agent setup.

### 10. win4r/Awesome-Claude-MCP-Servers
**URL**: https://github.com/win4r/Awesome-Claude-MCP-Servers
**Why it's Claude-specific**: Unlike the general `awesome-mcp-servers` lists, this one categorizes MCP servers specifically tested and optimized for Claude Code/Desktop. Includes:
- Installation guides for Claude Code
- Claude-specific configuration examples
- Compatibility notes for Claude models
- Categorized by use case (development, browsing, databases, etc.)

**Use this when**: You need MCP servers that are confirmed working with Claude Code, not just any MCP client.

**Why it matters (~1.5k stars)**: The most comprehensive single-hub for everything Claude. Unlike the other lists which specialize (skills, agents, MCP, cursor), this one covers the full Anthropic ecosystem:
- Official Anthropic resources and documentation
- Claude Code tools, CLI enhancements, and orchestrators
- MCP servers organized by category
- IDE extensions (VS Code, JetBrains, Cursor)
- Third-party apps and integrations
- Educational materials and tutorials

**Use this when**: You need a starting point for anything Claude-related — it's the "root" hub that links to all others.

### 13. e2b-dev/awesome-ai-agents
**URL**: https://github.com/e2b-dev/awesome-ai-agents
**Why it matters (~28.3k stars)**: The industry's most comprehensive directory of autonomous agents — 5,500+ line README functioning as a massive community-sourced index. Maintained by the E2B sandbox infrastructure company:
- **Organized by application domain**: Art & Culture, Browser Automation, Coding/DevTools, Data Analysis, Finance, Gaming, Healthcare, Research

- **Key difference from Jenqyang/kyrolabs**: E2B prioritizes breadth and discoverability over opinionated curation — it's a database, not a hand-picked list

**Use this when**: You're building or evaluating autonomous agents and need the broadest possible market landscape. Also use the companion `awesome-ai-sdks` for the infrastructure layer.

## 🆓 Free Claude Code Alternatives (New — June 2026)

These are NOT awesome lists but standalone tools that let you use Claude Code (or Claude-like coding agents) for free or with alternative backends.

### A. Rishurajgautam24/free-claude-code
**URL**: https://github.com/Rishurajgautam24/free-claude-code
**What it does**: A transparent proxy server (FastAPI, port 8082) that intercepts Claude Code's Anthropic API calls and routes them to free/cheaper providers:
- **NVIDIA NIM**: 40 req/min free tier (Kimi K2, GLM5, MiniMax M2.5)
- **OpenRouter**: Free models (DeepSeek R1, Step 3.5 Flash, GPT-OSS 120B)
- **LM Studio**: Fully local (no API key, unlimited)

**Key features**: Per-model routing (Opus→Kimi, Sonnet→DeepSeek, Haiku→Step), thinking token parsing, 5 categories of request optimization (saves quota), Discord/Telegram bot with live streaming, voice notes via Whisper.

**Use this when**: You want to keep using the official `claude` CLI/VSCode extension but don't want to pay for Anthropic API credits.

### B. Gitlawb/openclaude
**URL**: https://github.com/Gitlawb/openclaude
**What it does**: A standalone, fully open-source coding-agent CLI — NOT a proxy, but a complete reimplementation of the Claude Code experience with model-agnostic backend support. Written in TypeScript/Node.js, installable via `npm install -g @gitlawb/openclaude`.

**Supported backends**: OpenAI, Gemini, GitHub Models, Codex (OAuth + CLI), Ollama, Atomic Chat, LM Studio, Xiaomi MiMo, NEAR AI, OpenCode Zen/Go, Gitlawb Opengateway, and any OpenAI-compatible `/v1` API.

**Key features**: Same terminal-first workflow (bash, file tools, grep, agents, tasks, MCP, slash commands), VS Code extension with Control Center, gRPC server mode for CI/CD, per-agent model routing, Firecrawl web search, provider profiles via `/provider`.

**Use this when**: You want a completely free, open-source alternative to Claude Code that works with any LLM backend — no Anthropic dependency at all.

### Comparison

| Feature | free-claude-code | OpenClaude |
|---------|-----------------|------------|
| Type | Proxy (uses official Claude Code client) | Standalone CLI (no Claude Code needed) |
| Setup | Clone repo, configure .env, run proxy | `npm install -g`, run `openclaude` |
| Backends | 3 (NIM, OpenRouter, LM Studio) | 10+ (OpenAI, Gemini, Ollama, Codex, etc.) |
| Free tier | NVIDIA NIM 40 req/min, OpenRouter free models | Any free backend (Ollama local, free API tiers) |
| Discord bot | ✅ With live streaming | ❌ |
| VS Code ext | Uses official Claude Code extension | ✅ Custom extension with Control Center |
| MCP support | Via Claude Code | ✅ Native |
| gRPC server | ❌ | ✅ Headless mode |
| Best for | Staying with official Claude Code UX for free | Full independence from Anthropic ecosystem |
